# Biblioteca de ideas de motion graphics

`motion-ideas.json` viene de [yihui-dev/awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos)
(licencia MIT, ver `LICENSE-awesome-opus5-5-videos`): prompts que creadores compartieron para animaciones hechas
en código. Cada entrada enlaza al post original de su autor (`post`). Úsalas como punto de partida: el generador
de Emperador Santiago las adapta a formato vertical 9:16 y a la marca de Santi.
