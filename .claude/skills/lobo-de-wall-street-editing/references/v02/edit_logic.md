# v02 — Lógica de edición (FUERA DE ESTILO: anuncio "Tone", sin Jordan)

Estas reglas describen ESTE anuncio; no aplican al estilo Lobo.

1. Claim de apertura sin voz 2.7 s: línea 1 negra fija, línea 2 gris sube por máscara a 0.4.
2. Una frase hablada ("Can we talk?") = una escena; se repite 3 veces (2.74, 6.72, 10.24).
3. Cada tono tiene su color: azul (2.8–5.9), verde (6.0–10.3), magenta (10.4–14.3).
4. El cambio de color se anticipa hasta ~0.6 s a la voz (verde visible 6.1, voz 6.72).
5. Transición = fundido a crema + recoloreo de la cinta 3D (5.8–6.2, 10.2–10.6), nunca corte seco.
6. Texto re-entra por máscara de línea tras cada transición (6.1, 10.6).
7. Selector de 3 píldoras abajo (y ~83 %) indica el tono activo (negro relleno).
8. Contador "01 / 03" arriba-derecha como progreso.
9. Cierre en 3 líneas escalonadas cada 0.6 s (14.4 / 15.0 / 15.6), negro-gris-negro.
10. Logo final por partículas (16.4–17.0) y se sostiene ~2 s; probable música continua (RMS ≥ −28 dB).
