# FORMATOS

## Las 10 categorías de la biblioteca
| Categoría | Escena del sistema |
|---|---|
| `hook_title` | apertura + `p_word` |
| `aroll_caption` | (sin escena) |
| `aroll_punch` | `p_punch` |
| `aroll_text_overlay` | `p_word` |
| `split_graphic_top` | `p_split` |
| `card_video` | `p_card` |
| `full_graphic` | `p_full` |
| `whiteboard` | NO reproducible en edición: es grabación (pizarra/papel real, cámara cenital). Se recomienda al grabar. |
| `broll` | tarjetas de `p_split` cards (stock en blanco y negro) |
| `title_cta` | cierre a cámara · `p_card` |

## Los 4 formatos de video vistos
1. **Micrófono a pantalla completa** (v04–v12, v19): el formato base de esta skill.
2. **Tarjeta sobre negro** (v02, v03, v13, v16): todo el video dentro de `p_card`. v13 es 4:3 y v16 cuadrado.
3. **Pizarra / papel** (v01, v14, v15, v17, v18, v20): depende de la grabación; aquí solo se editan subtítulo, título fijo y cortes entre cámaras.
4. **Coche** (v16): tarjeta + iconos de línea.
