# Sound kit

Every sound here is made in code by `scripts/sfx.py` (numpy noise, sines and filters). Nothing is cut from a video or a sound
library, so the kit is free to use anywhere. It is off by default; `pc mix <dir> --sfx soft|full` turns it on.
Regenerate with `python -X utf8 scripts/sfx.py`.

click, notify, glitch, gear, pop, whoosh, whoosh_v, airy, wind, shutter, pluck, confirm, gui, dull, swipe, tick_up, tick_down,
bloom, shimmer, scribble, draw
